## 🛠️ Stack Tecnológico Seleccionado

* **Frontend & Framework:** Next.js 15+ (App Router) con React.
* **Estilos:** Tailwind CSS (Maquetado Glassmorphism adaptable).
* **Base de Datos Relacional:** PostgreSQL (Alojada en la nube mediante Supabase).
* **Mapeador Objeto-Relacional (ORM):** Prisma ORM.
* **Seguridad y Autenticación:** Tokens JWT (vía jose) y Hasheo de credenciales con bcrypt.
* **Control de Versiones & CI/CD:** GitHub conectado a Vercel para despliegues automatizados.

## 🛡️ Declaración de Madurez Metodológica (Ciclo de Vida)

**NOTA IMPORTANTE:**  
Este repositorio ha sido inicializado con la **arquitectura e infraestructura base del proyecto** (instalación limpia de dependencias, configuración de entornos locales/nube y pipeline de CI/CD en Vercel).

Sin embargo, en estricto cumplimiento con la **Ingeniería de Requerimientos** y la co-creación de valor propuesta por **ITIL 4**, la rama principal (`main`) **no contiene lógica de negocio codificada** en esta instancia. DeveloPet Friendly sostiene como principio de calidad que **no se debe escribir código de producción sin previa validación con el cliente**.

El desarrollo de los módulos de negocio se iniciará strictly de acuerdo al siguiente Roadmap:
1. **Hito 1 (Completado):** Entrevista de Relevamiento de Requisitos Sincrónica Grabada con la administradora Paula.
2. **Hito 2:** Diseño, refinamiento y aprobación por parte de la administradora del **Prototipo Interactivo en Figma**.
3. **Hito 3:** Firma de la Minuta de Conformidad de Requerimientos y apertura de ramas de desarrollo para codificación ágil de los sprints.
